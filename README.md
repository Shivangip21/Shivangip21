# TyrePlex Mini Order Flow System

Refer to individual folders for module implementations.

# For Frontend : run 'yarn' and then 'yarn dev' to start inside frontend folder.

# For Backend : run 'yarn' and then 'yarn start:dev' to start inside backend folder, install and run redis, mysql and kafka.

# For PHP Script : run ' php -S localhost:8000' to start the server and then run the following curl to fetch order details by order id or all orders.
# curl -H "Authorization: Bearer <TOKEN>" http://localhost:3001/orders/3 
# curl -H "Authorization: Bearer <TOKEN>" http://localhost:3001/orders
